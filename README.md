# TRP Application Builder — Website Replica

An exact, high-performance replica of [TRP Application Builder](https://tabapp.in/) (TAB) built with **React 19**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **Lucide Icons**.

---

## 🌟 Features

- **Hero Section**: Pulsing badge, gradient typography, and call-to-actions.
- **Interactive Screenshot Showcase**: Interactive tab switcher displaying high-resolution dashboard mockups within a browser window frame.
- **Everything You Need Feature Grid**: Grid of core TAB platform capabilities with icons and smooth motion effects.
- **Why Choose TAB Comparison Table**: Dark mode matrix table comparing TRP Application Builder vs Generic Trackers.
- **Founders & Story Section**: Narrative overview of Bay Education Partners Pvt Ltd.
- **Request Access Modal & Form**: Integrated access request popup modal + Google form links.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Theme**: HSL-tailored red/crimson accents (`#E11D48`) and modern typography (`Inter`)

---

## 🚀 Quick Start

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Local Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build

```bash
npm run build
```

## 📤 How to Push to GitHub

Follow these steps to upload this codebase to your GitHub account:

### Step 1: Create a New Repository on GitHub
1. Go to [GitHub New Repository](https://github.com/new).
2. Enter a repository name (e.g. `tabapp-website` or `trp-application-builder`).
3. Leave **"Initialize this repository with a README"** unchecked (since this project already contains a README).
4. Click **Create repository**.

### Step 2: Push Your Local Repository

Run the following commands in your terminal inside the project directory:

```bash
# Add all files to git tracking
git add .

# Create your first commit
git commit -m "Initial commit: Replicate TRP Application Builder website"

# Rename branch to main
git branch -M main

# Add your GitHub repository as remote (replace URL with your repository URL)
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# Push to GitHub
git push -u origin main
```
